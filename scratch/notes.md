# Scratch Notes

## Personal-repo shape

- Keep one clear entry file (`home/entry.yaml`) for runtime + permissions.
- Keep checks simple and local so every runtime can execute them.
- Keep a lightweight UI surface for quick operational context.

## Online pattern scan

- Multi-agent repos commonly separate `automations`, `validation`, and `ui`.
- "Evals as code" and lightweight CI checks are recurring patterns.
- Curated pattern repos emphasize predictable folder conventions over heavy tooling.
